# Day 14 Report

## Objective
Demonstrate a repeatable incident-response workflow for a social-engineering alert.

## Phases
Preparation, Identification, Containment, Eradication, Recovery, Lessons Learned.

## Simulated Containment
Account lock, session revocation, SOC notification, mail-log preservation, email quarantine, sender blocking, and sandbox analysis.

## Important
The implementation records proposed actions only; no external systems are changed.
