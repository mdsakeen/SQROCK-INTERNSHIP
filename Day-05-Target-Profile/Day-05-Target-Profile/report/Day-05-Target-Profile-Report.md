# Day 05 Report

## Objective
Demonstrate how public developer metadata can be combined into a threat profile.

## Data Collected
Name, company, location, public repository count, bio, and top repository languages.

## Attacker Perspective
Aggregated public data may reveal technology choices and organizational context that can inform social-engineering scenarios.

## Defender Perspective
Review public profiles regularly and remove unnecessary sensitive details.

## Privacy
Use authorized or anonymized data only; do not publish unrelated personal information.
