# Day 03 Report

## Objective
Identify common URL-level phishing indicators without creating or visiting phishing pages.

## Factors
- Non-HTTPS URL
- Suspicious security/account keywords
- Excessive subdomains
- Literal IP address as hostname

## Results
Use output/phishing_scores.json and a screenshot of the terminal.

## Defender Perspective
Use URL reputation, domain allow/deny controls, browser protections, email filtering, MFA, and user verification procedures.

## Limitation
A heuristic score is not a definitive verdict; legitimate sites may trigger indicators and sophisticated phishing URLs may evade simple rules.
